# RBMK-SIM documentation

RBMK-SIM is an **educational, qualitative** simulator inspired by the RBMK-1000
channel-type reactor. It exists to teach software engineering for safety-related
systems: deterministic simulation kernels, protection logic, formal specification,
structured logging, and safety-case writing.

```{important}
This is an educational toy, not a reactor model. All coefficients are simplified,
public, and non-operational. The simulator must not be used for reactor operation,
operator training, prediction, design, licensing, or real-world safety analysis.
See {doc}`safety_case/index` for the complete statement.
```
